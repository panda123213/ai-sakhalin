1. ПРОВЕРКА СТАТУСА
bash
git status
Что делает: показывает, какие файлы изменены, добавлены или готовы к коммиту.
Используй: всегда перед add и commit.

2. ДОБАВИТЬ ВСЕ ИЗМЕНЕНИЯ
bash
git add .
Что делает: добавляет все изменения (новые, изменённые, удалённые файлы) в индекс.
Используй: когда хочешь подготовить всё к коммиту.

3. ДОБАВИТЬ КОНКРЕТНЫЙ ФАЙЛ
bash
git add <имя_файла>
Что делает: добавляет только указанный файл.
Используй: когда нужно закоммитить только один файл, а не всё.

4. СОХРАНИТЬ ИСТОРИЮ (КОММИТ)
bash
git commit -m "краткое описание изменений"
Что делает: создаёт слепок изменений с комментарием.
Используй: всегда с осмысленным описанием (например, feat: добавил память агенту).

5. ОТПРАВИТЬ НА GITHUB
bash
git push
Что делает: загружает твои коммиты в облако (GitHub).
Используй: после каждого коммита, чтобы синхронизироваться.

6. СКАЧАТЬ ИЗМЕНЕНИЯ С GITHUB
bash
git pull
Что делает: загружает изменения из облака к тебе на компьютер.
Используй: если работаешь с кем-то в команде или переключаешься между ПК.

7. ПОСМОТРЕТЬ ИСТОРИЮ КОММИТОВ
bash
git log
Что делает: показывает список всех коммитов с хешами и сообщениями.
Используй: чтобы вспомнить, что ты делал неделю назад.

8. ПОСМОТРЕТЬ ИСТОРИЮ В СОКРАЩЁННОМ ВИДЕ
bash
git log --oneline
Что делает: показывает каждый коммит в одну строку (коротко и красиво).
Используй: чтобы быстро пролистать историю.

9. ОТМЕНИТЬ ИЗМЕНЕНИЯ В ФАЙЛЕ (НЕ ЗАКОММИЧЕННЫЕ)
bash
git checkout -- <имя_файла>
Что делает: возвращает файл к последнему сохранённому состоянию.
Используй: если испортил файл и хочешь вернуть предыдущую версию.

10. ОТМЕНИТЬ ПОСЛЕДНИЙ КОММИТ (НО ОСТАВИТЬ ИЗМЕНЕНИЯ)
bash
git reset --soft HEAD~1
Что делает: убирает последний коммит, но изменения остаются в индексе.
Используй: если забыл что-то добавить в коммит.

11. ОТМЕНИТЬ ПОСЛЕДНИЙ КОММИТ (ПОЛНОСТЬЮ)
bash
git reset --hard HEAD~1
Что делает: убирает последний коммит И удаляет изменения.
Используй: если коммит был полностью ошибочным (осторожно!).

12. ПОСМОТРЕТЬ ИЗМЕНЕНИЯ МЕЖДУ ВЕРСИЯМИ
bash
git diff
Что делает: показывает, что именно изменилось в файлах (построчно).
Используй: перед add, чтобы убедиться, что ничего лишнего.

🧠 ЗАПОМНИ ПОСЛЕДОВАТЕЛЬНОСТЬ (90% ВРЕМЕНИ)
bash
git status          # посмотреть, что изменилось
git add .           # добавить все изменения
git commit -m "..." # сохранить историю
git push            # отправить на GitHub
